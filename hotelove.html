  • Odzyskano endpoint API silnika Profitroom, który run 36 użył, ale nie zapisał: GET booking.profitroom.com/api/{slug}/availability?checkIn&checkOut&currency&occupancy%5B0%5D%5Badults%5D=2&occupancy%5B0%5D%5Bchildren%5D%5B%5D=5 z nagłówkiem X-Requested-With: XMLHttpRequest. Nawiasy kwadratowe muszą być kodowane procentowo. Dodatkowo /api/{slug}/rooms i /api/{slug}/offers dają nazwy pokoi, nazwy ofert i typ wyżywienia.
  • Nowe ustalenie: najtańsze stawki w Caryńskiej (1155 zł) i Poziomie 511 (2426 zł) to oferty bezzwrotne. Śniadanie potwierdzone w obu (mealPlanType 19), więc warunek monitora jest spełniony, ale elastyczność – nie.
  • Legacy rekord Caryńskiej 1110 zł z run 3: Triverna deklaruje dostawkę dla dziecka 4-12 lat po 150 zł/dobę, czyli +300 zł za weekend. Rekord 1110 zł był więc niemal pewnie ceną dla dwojki bez dziecka. Rekomendacja: wycofać go i uznać 1155 zł za jedyny ważny rekord.
  • Silnik własny mieści dziecko pięcioletnie w bazowej obsadzie pokoju Standard bez dopłaty (pole extraBedsIDs puste), natomiast Triverna wymusza płatną dostawkę. Ta sama nieruchomość, dwie różne reguły obsady.
  • Bachledka 30.10 pozostaje nieobecna na Bookingu przy 25 i 27 wolnych miejscach we własnym kalendarzu. To ograniczenie kanału, nie brak miejsc. Termin 2-4.10 nie wrócił – punkt obserwacyjny z run 36 zamknięty odpowiedzią negatywną.

  • Anti-false-negative zastosowany do obu zniknięć: Caryńska 9-11.10 nieobecna przy destination Bieszczady i przy powtórce z Dwernik, dodatkowo brak ofert w API własnym. Bachledka 6-8.11 nieobecna przy Bieszczady i przy Ždiar, dodatkowo piątek ma 0 miejsc własnych.
